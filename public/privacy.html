Política de Privacidade

Última atualização: 28 de Setembro de 2026 • Versão 2.1

1. Identificação da Aplicação e do Responsável

Esta Política de Privacidade descreve como o aplicativo Secretary AI Agent by Malves (acessível no domínio oficial secretary.malves.dev.br), mantido e operado pela organização Malves, coleta, utiliza, armazena, processa e protege os dados dos seus usuários.

O Secretary AI Agent by Malves é um sistema de assistência executiva e automação de produtividade corporativa destinado exclusivamente a organizar tarefas, gerenciar calendários e viabilizar fluxos operacionais internos autorizados.

Contato do Encarregado / Desenvolvedor: Maychel Alves (maychel.alvesz@gmail.com) — Curitiba/PR, Brasil.

2. Coleta e Uso de Dados de Usuários do Google

Nosso aplicativo integra-se com serviços do Google Workspace via OAuth 2.0 estritamente quando o usuário concede permissão explícita. Os dados acessados e as respectivas finalidades são:

  • Google Calendar (Escopos: calendar, calendar.events): Acessamos sua agenda exclusivamente para: (a) Consultar horários livres e evitar conflitos de compromissos; (b) Inserir reuniões e eventos solicitados pelo usuário; (c) Gerar links automáticos de videoconferência do Google Meet para os participantes do evento.
  • Google Tasks (Escopo: tasks): Utilizado para listar suas tarefas pendentes de hoje e da semana, criar novas tarefas solicitadas pelo usuário e marcar afazeres concluídos.
  • Google Contacts / People API (Escopo: contacts.readonly): Acessado de forma somente-leitura unicamente para localizar endereços de e-mail de contatos salvos quando o usuário solicita o agendamento de uma reunião com determinada pessoa.
  • Gmail (Escopos: gmail.readonly, gmail.send): Utilizado estritamente para: (a) Leitura sob demanda de e-mails recentes quando o usuário solicita um resumo de mensagens recebidas; (b) Envio de convites de agenda, confirmações de reunião ou e-mails formais explicitamente ditados e aprovados pelo usuário.
  • Informações de Perfil e E-mail (Escopos: userinfo.email, userinfo.profile): Utilizados apenas para exibir a conta conectada na interface administrativa do painel e associar as credenciais ao usuário correto.

3. Conformidade com a Política de Dados do Usuário do Google

Conformidade Obrigatória com a Google API Services User Data Policy:

O uso e a transferência para qualquer outro aplicativo de informações recebidas das APIs do Google pelo Secretary AI Agent by Malves cumprirão rigorosamente a Política de Dados do Usuário dos Serviços de API do Google (Google API Services User Data Policy), incluindo os requisitos de Uso Limitado (Limited Use Requirements).

Proteção contra Treinamento de Inteligência Artificial:
Os dados de usuários obtidos a partir das APIs do Google (conteúdo de e-mails, eventos de calendário, tarefas e contatos) NÃO são utilizados para treinar, retreinar ou aprimorar modelos fundacionais de Inteligência Artificial ou Aprendizado de Máquina (LLMs) generalizados. Os dados são processados de forma efêmera em memória unicamente para executar a ação executiva imediata solicitada.

4. Não Compartilhamento e Não Venda de Dados

Nós NÃO vendemos, NÃO alugamos e NÃO comercializamos dados de usuários sob nenhuma circunstância.

Seus dados do Google ou de qualquer outra integração nunca são repassados a terceiros, corretores de dados (data brokers) ou redes de publicidade. O compartilhamento ocorre unicamente:

  • Com os próprios servidores da Google para efetuar as ações solicitadas pelo usuário;
  • Caso estritamente exigido por determinação judicial ou cumprimento de lei aplicável.

5. Armazenamento, Segurança e Retenção de Dados

Armazenamento Seguro: Os tokens de autenticação OAuth (Access Tokens e Refresh Tokens) são armazenados em banco de dados relacional protegido (MariaDB) em servidor próprio com acesso restrito, firewalls rigorosos e comunicação exclusivamente criptografada via HTTPS/TLS.

Retenção Efêmera: Não mantemos cópia permanente ou arquivamento de e-mails completos nem de calendários inteiros nos nossos servidores. Os dados são consultados em tempo real na API do Google e apresentados em tela para o usuário.

Segurança da Informação: Adotamos padrões modernos de segurança da informação, incluindo cabeçalhos HTTP de proteção estrita (HSTS, CSP, proteções anti-traversal) e isolamento em containers Docker dedicados.

6. Como Revogar Acessos e Excluir seus Dados

O usuário tem total controle sobre suas credenciais e pode revogar o acesso do Secretary AI Agent by Malves a qualquer momento por meio de dois métodos simples:

  • No próprio painel do sistema: Acesse a aba de integrações ou configurações e clique em "Desconectar Conta Google". O token de acesso e de atualização serão imediatamente e permanentemente apagados do nosso banco de dados.
  • Diretamente na Conta Google: Acesse a página oficial de segurança do Google em Permissões de Aplicativos da Conta Google, selecione Secretary AI Agent by Malves e clique em "Remover acesso". A revogação terá efeito imediato em nível mundial.

7. Atualizações desta Política e Canal de Contato

Esta política pode ser atualizada periodicamente para refletir melhorias no sistema ou novos requisitos regulatórios. Sempre que houver qualquer alteração substancial no tratamento de dados, a data de atualização no topo deste documento será revisada.
